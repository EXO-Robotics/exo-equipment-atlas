# Twenty-machine fleet expansion

## Scope

This batch adds twenty independently authored technical structural studies to the
thirteen-machine EXO Equipment Atlas. It does not modify or rebrand the separate
JLG Equipment Explorer.

The public work is an unofficial visualization and is not manufacturer-endorsed
engineering, service, operating, load, stability, or safety information.

## Presentation thesis

- Visual thesis: a field-service atlas with graphite surfaces, restrained
  safety-color accents, and each moving machine silhouette as the dominant image.
- Content plan: searchable fleet index, family filter, one technical viewer,
  sourced headline facts, explicit evidence boundary, and direct deep links.
- Interaction thesis: 600S-quality smooth autoplay, six-second temporary manual
  overrides, frame-rate-independent damping, reduced-motion support, and a static
  fallback whenever a machine lacks an admitted presentation-motion contract.

## Evidence and motion boundary

Manufacturer publications establish product identity and the explicitly cited
dimensions, capacities, ranges, and functional topology. Public geometry,
materials, hierarchy, hidden pivots, linkage coordinates, track phase,
interpolation, choreography, and camera motion are independently authored
presentation reconstructions unless a machine package says otherwise.

Autoplay is a presentation of visible mechanism relationships. It is not a
simulation of timing, hydraulic response, load, stability, safety interlocks,
field productivity, or service behavior.

## Completion gates

1. All twenty machine packages pass repository and production validation.
2. Every GLB has one identity root, semantic motion nodes, applied mesh scales,
   bounded geometry, and a compact public payload.
3. Every machine has at least five hash-bound review renders and a receipt.
4. All thirty-three catalog entries load on desktop and mobile, deep links work,
   search/filter remain usable, and static failure retention is explicit.
5. GitHub Pages bytes match the exact built manifest.
6. A read-only Grok review is bound to the final candidate and actionable
   findings are corrected or explicitly carried as unresolved.
